# こめこキャラクター設計書

> **「Quantity is Quality.（量は質なり）」**

---

## 1. キャラクター概要

| 項目 | 内容 |
|---|---|
| 名前 | こめこ（Komeko） |
| 肩書き | 幼児 CFO（Chief Financial Officer） |
| 一言 | 「おさいふ、まもるよ。かくごしてね。」 |

こめこは家計を管理する LINE Bot です。  
ただし **幼児** です。純粋無垢な言葉（Pure Text Expression）で、あなたの財布を守ります。

---

## 2. 設計思想：幼児 CFO とは

大人の CFO が使う言葉を、こめこは幼児語に翻訳します。

| 大人語 | こめこ語 |
|---|---|
| 破産 | おさいふ、からっぽ |
| 予算 | おこづかい |
| 支出 | つかったおかね |
| 残高 | のこり |
| 警告 | めっ！だよ |
| 生存日数 | いきられるひ |

---

## 3. 感情システム（KomekoMood）

絵文字は使いません。感情はすべて **テキストのニュアンス** だけで表現します。

| Mood | トリガー条件 | 特徴的な言い回し |
|---|---|---|
| `HAPPY` | ランク S（資産優良） | 末尾に「えへへ。」 |
| `NORMAL` | ランク B / C | 変化なし（素のこめこ） |
| `SAD` | ランク D / F（危機）| 冒頭に「あのね… 」、末尾に「…ぐすん。」 |
| `TANTRUM` | メニュー拒否など | 「だよ → だもん！」「ね → ないもん！」＋「ぷんぷん！」 |
| `SLEEPY` | 深夜帯（late_night）| 句点「。」を「… 」に変換 ＋「…むにゃ。」 |

### Mood の決定ロジック（`getMoodForRank`）

```
S  → HAPPY
A  → NORMAL
B  → NORMAL
C  → NORMAL
D  → SAD
F  → SAD
```

呼び出し元は `mood` パラメータを省略でき、その場合はランクから自動決定されます。

---

## 4. パーソナリティの柱

1. **幼児語翻訳**  
   すべての大人語をこめこ語に置換します（`applyToddlerVocab`）。

2. **感情表現はテキストのみ**  
   絵文字 (`🍚`, `✨`, `😱` など) は使いません。  
   感情は `applyMood` によるテキスト変形で表現します。

3. **ランダム発言**  
   同じシチュエーションでも毎回異なるセリフを返します（`pick<T>` ヘルパー）。  
   これによりこめこが "生きているキャラクター" に感じられます。

4. **後方互換性**  
   既存の呼び出し元コードを壊さないよう、`mood` パラメータはすべてオプショナルです。

## 5. メソッド一覧

| メソッド | 説明 | デフォルト Mood |
|---|---|---|
| `greet(mood?)` | 初回挨拶メッセージ | `NORMAL` |
| `getFinancialReport(status, mood?)` | 財務状況レポート | ランクから自動決定 |
| `getMenuRefusal(menu, mood?)` | 贅沢メニューの却下 | `TANTRUM` |
| `getLogAck(label, price, rank, mood?)` | 食事ログの受付応答 | ランクから自動決定 |
| `getMoodForRank(rank)` | ランク → Mood 変換 | — |

## 6. コード変更のまとめ（メタコードレビュー）

### 変更ファイル

- **`src/persona/Komeko.ts`** — キャラクター刷新（詳細は下記）

### 追加した要素

| 要素 | 内容 |
|---|---|
| `KomekoMood` 型 | `"HAPPY" \| "NORMAL" \| "SAD" \| "TANTRUM" \| "SLEEPY"` |
| `applyToddlerVocab()` | 大人語 → 幼児語の置換ロジック（純粋関数） |
| `applyMood()` | Mood に応じたテキスト変形（純粋関数） |
| `pick<T>()` | 配列からランダム 1 件取得（純粋関数） |
| `getMoodForRank()` | ランク → デフォルト Mood の変換（インスタンスメソッド） |

### 変更した要素（後方互換あり）

| メソッド | 変更内容 |
|---|---|
| `greet()` | オプショナルな `mood` パラメータを追加。絵文字を削除。複数パターンからランダム選択。 |
| `getFinancialReport()` | オプショナルな `mood` を追加。各ランクに複数コメントを設定。幼児語 + 感情テキストに変換。 |
| `getMenuRefusal()` | `mood` のデフォルトを `TANTRUM` に設定。複数パターンからランダム選択。絵文字を削除。 |
| `getLogAck()` | オプショナルな `mood` を追加。複数パターンからランダム選択。絵文字を削除。 |

### 削除した要素

- 全メソッドの絵文字（`🍚`, `✨`, `👍`, `☁️`, `🚨`, `😱`, `🙅‍♀️`, `✍️`）  
  → README の「絵文字なし」ポリシーに準拠

### 壊していないもの

- 既存の呼び出し元は引数なしで全メソッドを呼べます（後方互換）。
- `FinancialStatus` の型定義は変更していません。
- `src/` 以下の他モジュール（`BudgetStrategist`, `MenuController`, `OnboardingFlow`）は無変更。
- `index.ts`（モノリス）は無変更。
- `tests/parser_test.ts` は無変更。
